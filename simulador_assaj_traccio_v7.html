Simulador d'assaig de tracció

Selecciona una mostra, introdueix dimensions (o deixa les per defecte) i inicia la simulació. Es dibuixa la corba Força–Allargament a partir de les dades de la base, i pots copiar/exportar les dades per treballar-les a Excel.

—
F màx. (N)
—
Treball a Excel: ε = ΔL/L₀, σ = F/A₀. Pots calcular E amb la pendent inicial i el límit elàstic amb offset 0,2%.
Si el navegador bloqueja la reproducció automàtica, fes clic al vídeo una vegada i torna a prémer “Inicia assaig”.
